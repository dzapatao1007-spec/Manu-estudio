# MANU STUDIO — Haute Couture Lash & Brow ✨

Sitio web oficial y boutique interactiva para **MANU STUDIO**. Especialistas en diseño de cejas, visagismo anatómico, extensiones de pestañas pelo a pelo, lifting de pestañas y laminado de cejas.

---

## 🚀 Despliegue Rápido en Vercel (1-Click)

Este proyecto está 100% optimizado y listo para ser desplegado en **Vercel** sin necesidad de configuraciones complejas adicionales.

### Opción A: Despliegue directo desde GitHub (Recomendado)
1. Sube este repositorio a tu cuenta de **GitHub**.
2. Ve a [vercel.com](https://vercel.com) e inicia sesión.
3. Haz clic en **"Add New..."** → **"Project"**.
4. Selecciona tu repositorio de GitHub `manu-studio`.
5. Vercel detectará automáticamente la configuración gracias al archivo `vercel.json` incluido:
   - **Framework Preset**: `Vite`
   - **Build Command**: `npm run build`
   - **Output Directory**: `dist`
6. Haz clic en **"Deploy"** y ¡listo! Tu sitio web estará en línea con dominio gratuito `.vercel.app` o tu propio dominio personalizado.

## 📦 Ejecución en Desarrollo Local

Para probar o editar el sitio en tu computadora local:

```bash
# 1. Instalar dependencias
npm install

# 2. Iniciar servidor de desarrollo
npm run dev

# 3. Compilar para producción
npm run build
```

## 💎 Características Principales

- 👑 **Diseño Haute Couture & Apple Aesthetic**: Paleta rosada sutil, marfil, acentos dorados y efectos de cristal líquido (Liquid Glass).
- 🪄 **Asistente Interactivo de Visagismo**: Test inteligente de 3 pasos que recomienda el tratamiento ideal según las facciones y rutina de la clienta.
- 🔄 **Galería Antes & Después Interactiva**: Slider táctil para comparar resultados en tiempo real con filtros por categoría.
- 📱 **Reserva Inteligente por WhatsApp**: Formulario guiado que genera el mensaje listo para coordinar cita directamente en WhatsApp.
- 👑 **Panel de Administradora en Vivo**: Edición en tiempo real con guardado automático en Firebase de todos los textos, imágenes, precios, políticas y preguntas frecuentes.
- 🛡️ **Sección de Políticas de Cita & Bioseguridad**: Pautas de puntualidad, higiene y abono de cita.
- 📸 **Feed de Instagram Integrado**: Escaparate visual conectado a la comunidad social.
